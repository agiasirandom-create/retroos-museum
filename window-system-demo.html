Window System Demo

Welcome to the RetroOS Museum window management system!

Features:

  • Drag windows by title bar
  • Resize using edges/corners
  • Minimize/Maximize/Close buttons
  • Double-click title to maximize
  • Multi-select desktop icons
  • Right-click context menus
  • Keyboard shortcuts

Keyboard Shortcuts:

  • Alt+F4 - Close window
  • Alt+Tab - Switch windows
  • Ctrl+A - Select all icons
  • Esc - Close menus
