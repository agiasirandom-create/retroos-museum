## Using the Desktop

### Desktop Icons
- **Macintosh HD**: Double-click to open Finder
- **Trash**: Double-click to view trash contents
- **Single-click**: Selects an icon
- **Double-click**: Opens the item

### Menu Bar (Always at Top)
- **Apple Menu ()**: System information and settings
- **File**: File operations and folder management
- **Edit**: Cut, copy, paste, undo operations
- **View**: Change how Finder displays items
- **Special**: System commands like Restart and Shut Down
- **Help**: Help topics (demo)

### Menu Tips
- Click a menu to open it
- Click outside or press Esc to close
- Use Command (⌘) key shortcuts
- Disabled items are grayed out

## Keyboard Shortcuts

### Universal Shortcuts
- **⌘N**: New Folder (in Finder)
- **⌘O**: Open selected item
- **⌘W**: Close active window
- **⌘Q**: Quit/Close all windows
- **⌘A**: Select All
- **⌘I**: Get Info

### Text Editing (SimpleText)
- **⌘X**: Cut
- **⌘C**: Copy
- **⌘V**: Paste
- **⌘Z**: Undo
- **⌘S**: Save

### System
- **⌘E**: Eject (disabled in demo)
- **Esc**: Close menu

## Opening Applications

### From Finder
1. Double-click **Macintosh HD** on desktop
2. Double-click **SimpleText** to open text editor
3. Double-click **Applications** or **Documents** folders

### From Menu Bar
1. Click **Apple Menu** (  icon)
2. Select **Control Panels**
3. Double-click any control panel to open it

## Using Finder

### Icon View (Default)
- Shows files and folders as icons
- Click to select, double-click to open
- Multi-select: Hold ⌘ and click multiple items

### List View
1. Click **View** menu
2. Select **by Name**, **by Date**, **by Size**, or **by Kind**
3. View switches to table layout

### View Options
- **by Icon**: Grid of icons with labels
- **by Name**: Alphabetical list
- **by Date**: Sorted by modification date
- **by Size**: Sorted by file size
- **by Kind**: Grouped by file type

## Using SimpleText

### Opening SimpleText
1. Open Finder (double-click Macintosh HD)
2. Double-click **SimpleText** icon
3. A blank document window opens

### Editing Text
- Click in the text area and start typing
- Text automatically wraps
- Window can be resized by dragging grow box (bottom-right corner)

### Saving
- Press **⌘S** or use File menu
- Currently shows "saved" confirmation (demo mode)
- Modified files show asterisk (*) in title

## Using Control Panels

### Opening Control Panels
1. Click **Apple Menu** ()
2. Select **Control Panels**
3. Control Panels folder window opens

### Available Panels
- **General Controls**: Desktop settings, menu blinking
- **Sound**: Alert sounds and volume
- **Monitors**: Display resolution and colors
- **Mouse**: Tracking speed and double-click rate
- **Keyboard**: Key repeat settings
- **Date & Time**: System date and time
- **Memory**: Memory usage and virtual memory
- **Startup Disk**: Boot disk selection

### Using a Panel
1. Double-click any control panel icon
2. Adjust settings using checkboxes, sliders, buttons
3. Changes are simulated (demo mode)
4. Close window when done

## Window Management

### Moving Windows
- Click and drag the title bar (striped area)
- Release to drop window in new position

### Resizing Windows
- Click and drag the **grow box** (bottom-right corner)
- Diagonal lines indicate the grow box
- Only works on resizable windows

### Closing Windows
- Click the **close box** (small square in top-left corner)
- Or press **⌘W**
- Modified documents will prompt before closing

### Window Focus
- Click anywhere on a window to bring it to front
- Active window has striped title bar
- Inactive windows have gray title bar

## System Features

### About This Macintosh
1. Click **Apple Menu** ()
2. Select **About This Macintosh...**
3. View system version and memory information
4. Click **OK** to close

### Empty Trash
1. Click **Special** menu
2. Select **Empty Trash...**
3. Confirm the operation
4. Trash icon updates to show empty state

### Restart
1. Click **Special** menu
2. Select **Restart**
3. Confirm to reload the page

### Shut Down
1. Click **Special** menu or **Apple Menu**
2. Select **Shut Down**
3. Confirm to return to museum homepage

## Tips & Tricks

### Mac Behavior Differences
- **Single-click** to select (not double-click)
- Menu bar is **always at top** of screen
- Use **⌘ (Command)** key, not Ctrl
- No minimize button (use close instead)
- No taskbar (windows managed spatially)

### Hidden Features
- **Get Info**: ⌘I shows detailed item information
- **Select All**: ⌘A selects all items in Finder
- **Close Menu**: Esc key closes active menu
- **Chooser**: Access from Apple Menu (simplified demo)

### What's Demo/Simulated
- File operations (New Folder, Duplicate, etc.)
- Printing functionality
- Network/AppleTalk features
- Some menu items are disabled
- Settings changes don't persist
- No actual file system

### Full Features
- Window dragging and resizing
- Menu bar navigation
- Icon selection and opening
- Text editing in SimpleText
- View switching in Finder
- Control panel interfaces
- Keyboard shortcuts
- Multi-window management

## Troubleshooting

### Menu Won't Open
- Click directly on menu text
- Release click after opening
- Try closing other menus first (Esc key)

### Window Won't Move
- Click and hold on striped title bar area
- Avoid clicking window controls
- Make sure window isn't maximized

### Can't Type in SimpleText
- Click inside the text area first
- Check that window has focus (striped title bar)
- Try clicking window to activate it

### Shortcut Keys Not Working
- Use Command (⌘) key on Mac keyboard
- On Windows/Linux, Ctrl key should work
- Make sure caps lock isn't interfering

### Window Disappeared
- Click elsewhere and press ⌘Q to close all
- Reload page to start fresh
- Check behind other windows

## Historical Context

### About System 7
- Released: May 13, 1991
- Apple Computer, Inc.
- Successor to System 6
- First Mac OS with:
  - Virtual memory
  - Personal file sharing
  - Cooperative multitasking
  - Color icons

### Design Philosophy
- Spatial file management
- Global menu bar
- Single-button mouse
- Desktop metaphor
- Consistent UI across apps

### Legacy
- Foundation for Mac OS 8/9
- Design patterns used for 10+ years
- Influenced modern macOS design
- Educational value for UI/UX history
