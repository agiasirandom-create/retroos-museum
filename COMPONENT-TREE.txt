Usage Pattern
-------------

1. Import Component:
   {% import "_includes/components/window.njk" as windowComponent %}

2. Use Simple Version:
   {{ windowComponent.simpleWindow(title="About", content="<p>Info</p>", osStyle="win95") }}

3. Or Use Call Block:
   {% call windowComponent.window(title="App", osStyle="macos") %}
     <p>Complex content here...</p>
   {% endcall %}

Color Schemes
-------------

Windows 95/98:
  Background: #c0c0c0 (Silver gray)
  Active:     #000080 → #0997ff (Blue gradient)
  Inactive:   #808080 → #c0c0c0 (Gray gradient)
  Text:       #000000 (Black)
  Highlight:  #dfdfdf (Light gray)
  Shadow:     #808080 (Medium gray)
  Dark:       #000000 (Black)

Mac OS Classic:
  Background: #ffffff (White)
  Title Bar:  #000000 (Black stripes on white)
  Inactive:   #ffffff (White with black border)
  Text:       #000000 (Black)
  Selection:  #000000 (Black with white text)
  Border:     #000000 (Black, 1-2px)
  Gray:       #dddddd (Light gray)

Unix/Linux X11:
  Background: #b8b8b8 (Medium gray)
  Active:     #4a90d9 → #2a70b9 (Blue gradient)
  Inactive:   #b8b8b8 → #686868 (Gray gradient)
  Text:       #000000 (Black)
  Highlight:  #e8e8e8 (Light gray)
  Shadow:     #686868 (Dark gray)
  Darker:     #383838 (Darkest gray)


Accessibility
-------------

ARIA Roles:    dialog, menu, menuitem, button, scrollbar
ARIA Labels:   All interactive elements labeled
ARIA States:   disabled, checked, expanded, haspopup
Keyboard:      Tab, Enter, Space, Arrows (with JS)
Focus:         Visible indicators on all elements
Contrast:      WCAG AA compliant
Screen Reader: Semantic HTML, hidden decorative elements


Performance
-----------

CSS Size:      ~15KB total (unminified, ~5KB minified)
Components:    Pure CSS (no JS required for styling)
DOM Depth:     Max 3-4 levels per component
Load Time:     <3 seconds target
Browser:       Chrome 90+, Firefox 88+, Safari 14+

Quick Start
-----------

1. Import components in your template:

   {{ win.simpleWindow(title="Hello", content="<p>World</p>", osStyle="win95") }}

3. CSS is auto-included via main.css

4. View demo: /components-demo.njk
